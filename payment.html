روش‌های پرداخت

درگاه‌های پشتیبانی‌شده برای اتصال نهایی

زرین‌پال

محبوب‌ترین درگاه ایران. با Merchant ID و API درخواست پرداخت ساخته می‌شود و کاربر به صفحه زرین‌پال هدایت می‌گردد.

آیدی‌پی (IDPay)

درگاه جایگزین با API ساده. مناسب برای اتصال سمت سرور یا سرویس میانی.

نکست‌پی

پرداخت بانکی سریع. پس از تأیید، callback به سایت شما بازمی‌گردد.

نکته فنی

سایت فعلی استاتیک است (GitHub Pages). برای پرداخت واقعی نیاز به یک بک‌اند کوچک (مثلاً Node یا PHP) دارید که:

  • مبلغ و سفارش را ثبت کند
  • از API درگاه Authority بگیرد
  • کاربر را به درگاه بفرستد
  • پس از بازگشت، پرداخت را Verify کند

در نسخه فعلی، دکمه پرداخت یک شبیه‌ساز درگاه باز می‌کند تا جریان خرید کامل تست شود.
